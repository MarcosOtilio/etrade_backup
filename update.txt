[Novidades da Versão 1.3.0]

Adicionado sistema de verificação de atualizações automáticas.

Nova janela para visualizar o changelog e baixar novas versões.

[Melhorias]

A interface foi reorganizada em duas colunas para melhor visualização.

O arquivo de configuração (config.json) agora é salvo na pasta de dados do usuário (%APPDATA%), evitando problemas de permissão.

Adicionada uma janela "Sobre" com informações do projeto.

Melhorias na detecção de drivers ODBC do SQL Server para maior compatibilidade.

[Novas Funcionalidades]

Opção para compactar automaticamente os backups em formato .zip.

Possibilidade de adicionar múltiplos locais para salvar cópias de segurança.
